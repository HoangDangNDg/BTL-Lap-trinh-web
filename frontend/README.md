# EduCenter Frontend (React 19 + Vite + Tailwind CSS)

Hệ thống giao diện quản trị trung tâm đào tạo đa chi nhánh EduCenter.

---

Mọi lập trình viên và trợ lý AI tham gia phát triển dự án này bắt buộc phải đọc và tuân thủ:

1. 📘 [REACT_ARCHITECTURAL_STANDARD.md](./REACT_ARCHITECTURAL_STANDARD.md) - **Bộ quy chuẩn kiến trúc và quy tắc phát triển React tối ưu** (Bảo mật HttpOnly Cookie, Virtual DOM Optimization, AbortController, React.memo, useCallback, useMemo, Data Contract Types).

## Scripts Khởi Chạy

```bash
# Cài đặt thư viện phụ thuộc
npm install

# Khởi chạy môi trường phát triển (Dev Server tại http://localhost:5173)
npm run dev

# Biên dịch sản phẩm (Production Build)
npm run build

# Kiểm tra cú pháp và linter
npm run lint
```
